**ResearchGen**  | **Next.js**, **FastAPI**, **Transformers** (BART, Flan-T5), **SciBERT**, **Sentence-Transformers**, **LoRA**, **arXiv API**, **Groq**, **Gemini**, **TipTap**
- Built a **multi-agent AI research assistant** that automates the academic paper writing pipeline — from topic analysis to draft generation with plagiarism checking. Implemented **7 specialized Python agents**: Query (keyword extraction via **SciBERT** + **KeyBERT**), Retrieval (real-time **arXiv** paper fetching with relevance scoring), Summarization (hierarchical text summarization using **BART** with **Groq/Gemini** fallback), Drafting (section generation using **Flan-T5**), Plagiarism Detection (sentence-level semantic similarity using **Sentence-Transformers** and **cosine similarity**), Citation (intelligent in-text citation insertion in **APA/IEEE/MLA** formats), and Diagram (text-to-**Mermaid.js** diagram generation).
- Developed a **Next.js 16** frontend with a **TipTap** rich-text editor for an **IEEE-compliant Universal Research Formatter** featuring live **A4 preview**, deterministic IEEE Conference/Journal formatting, and **LaTeX (.tex) / PDF export**. Built a **LoRA-based fine-tuning pipeline** for the drafting agent using pattern-based training data extracted from completed research projects, and exposed all agents through a **FastAPI REST API** with typed **Pydantic** schemas.
